# 单反相机（device=13）JSON 与红外格式

[返回通用说明](../README.md)

数据来自 [ysard/mi_remote_database](https://github.com/ysard/mi_remote_database)。

## 数据位置与数量

```text
13_Camera.json
13_Camera/<brand>_<brandId>.json
13_Camera/models/<modelId>.json
```

- 品牌：12；
- 型号：18；
- 型号全部来自 `others`；
- 字符串 key：116；
- 反向 key：0；
- 型号 ID 全部以 `kk_` 开头。

## 代表性数据示例

这里选择松下 `kk_13_137_12127`。除快门外，它还有录像、回放、菜单和方向控制，能够代表码库中功能较完整的相机遥控器：

```text
13_Camera.json
  → 13_Camera/Panasonic_137.json
    → others[]._id 中的 kk_13_137_12127

```

### `shutter` 功能的完整处理过程

`kk_13_137_12127.json` 的原始快门字段：

```json
{
  "version": 1002,
  "_id": "kk_13_137_12127",
  "frequency": 37910,
  "key": {
    "shutter": "RXAxXnAqiFlbJDtewkAx0nuYWszMDoJuM4wZWwQnmIPnYofmkNSHVz8I2S8KQMJNhwZUIUZ8yyZAJ42TsFcyw4yxQDYf/RL54JQP9EbRCTwk74Iw+HcK8nIqRfOCSj+10dqOp3y+xfnuOEt7fml2MQ=="
  }
}
```

1. `RemoteCatalog.loadRemote()` 读取 37910 Hz，`fixedCommands()` 使用 `key.shutter` 创建快门命令。
2. `FixedIrTransmitter.transmit()` 找不到 `shutter_r`，因此始终使用上面的正向码。
3. `FixedIrDecoder.decode()` 得到 200 个微秒时长，总时长 265410 µs。数组本身已经包含重复的两帧快门协议，发送层不再额外重复。
4. 最终发送：

## 按键结构

代表性按键：

```text
shutter, power, menu, play
up, down, left, right, ok
stop, pause, REW
```

`shutter` 是出现最多的相机专用按键。部分型号还包含回放和方向控制。

## 载波

- 范围：32700～38200 Hz；
- 最常见：37910 Hz，共 12 个型号。

## 编码结论

全部型号都是固定码，没有反向码，也没有动态状态结构。
