## 代表性数据示例

这里选择 LG 的 `xm_1_276`。它由品牌文件的 `tree.nodes[].keysetids[]` 引用，包含电视常见的电源、音量、频道、方向、输入源和菜单按键，适合代表 XM 电视固定码结构：

```text
1_TV.json
  → 1_TV/LG_22.json
    → tree.nodes[].keysetids[] 中的 xm_1_276
      → 1_TV/models/xm_1_276.json
```

型号文件的真实结构摘录如下。Base64 密文正文很长，示例只省略密文，不省略字段名、型号参数和按键名：

```json
{
  "data": {
    "_id": "xm_1_276",
    "version": 1009,
    "frequency": 37870,
    "seceret_key": null,
    "key": {
      "power": "<Base64 密文省略>",
      "vol+": "<Base64 密文省略>",
      "vol-": "<Base64 密文省略>",
      "ch+": "<Base64 密文省略>",
      "ch-": "<Base64 密文省略>",
      "input": "<Base64 密文省略>",
      "menu": "<Base64 密文省略>"
    }
  }
}
```

这个例子还说明 `frequency` 必须跟随型号读取：LG 样本是 37870 Hz，并不是常被写死的 38000 Hz。

### `power` 功能的完整处理过程

下面是从 `xm_1_276.json` 抽取并格式化的原始字段，Base64 值没有省略：

```json
{
  "version": 1009,
  "seceret_key": null,
  "frequency": 37870,
  "_id": "xm_1_276",
  "key": {
    "power": "EfzCDHFZzIWDiDH+JCr+FWgXdeMBOcv4i0KsONPcPDxxXhLZCpeyyLLBwqlqJ0wswFcS6HH/OXB1w7vcawFau9aKmzf+MbnHkGLxKnksoIBHkIOj6mft0IXjri0nTOhPDWqhm+l4hpVG5PDOFnVw/g=="
  }
}
```

1. `RemoteCatalog.loadRemote()` 读取 `_id`、`frequency` 和 `key`，`fixedCommands()` 把 `key.power` 建成 `RemoteCommand`。这个型号存在 `power`，但示例发送的这一条不使用 `tree.nodes[].ir_zip_key`，而是使用型号文件中的 `key.power`。
2. `FixedIrTransmitter.transmit()` 取得正向码。若型号还有 `power_r`，下一次调用才会选择反向码。
3. `FixedIrDecoder.decode()` 依次执行 Base64、`AES/ECB/NoPadding`、删除尾部 `0x20`、GZIP 和 Gson，得到 72 个微秒时长，总时长 216000 µs。
4. 最终调用内容如下，数组是实际解密结果：

## 型号结构

正常型号的 `data` 包含：

```text
_id
frequency
key
version
seceret_key（部分文件存在）
```

`key` 中的值全部是字符串固定码，没有空调 `type=2` 那种状态规则。

代表性按键：

```text
power, vol+, vol-, ch+, ch-, mute
0～9, up, down, left, right, ok
menu, input, back, home
```

当前共发现 118226 个字符串 key，其中 12410 个名称以 `_r` 结尾。

## 载波

- 最常见：38000 Hz；
- 当前有效数据最高：57900 Hz；
- `xm_1_1137` 的频率是 0，不能直接发送。

频率必须按型号读取，不能统一写成 38000 Hz。

## 编码结论

电视走通用固定码路径：

```text
Base64 → AES-256-ECB/NoPadding → GZIP → JSON int[] → ConsumerIrManager
```

AES 公共密钥是：

```text
fd7e915003168929c1a9b0ec32a60788
```

它是 32 个 ASCII 字节，不是需要十六进制解码的 16 字节数据。ECB 不使用 IV；解密后先删除尾部 `0x20` 填充空格，再执行 GZIP 解压。

电视没有动态状态编码。电源、音量和频道等按键均按各自固定码发送。
